02Built for hybrid monetization

Our first three games shipped free and ad-free so we could measure pure gameplay first. From Needle Trail onward, every game runs on our own monetization layer, built into our game skeleton.

  • Ads: interstitials only between levels, never before level 6, capped per session. Rewarded video for doubling rewards, hints and continues.
  • Purchases: remove ads, coin packs, a one-time starter pack, a piggy bank.
  • Economy: one currency. Lives where a game has a fail state, a hint economy where it does not.
  • Rules we keep: no fake timers, no hidden prices, every level beatable without paying. We check this with 1,000 simulated non-paying players per game.
  • User acquisition: playable ads built from the game's real rules, in three variants per game.

Status: running in development builds. Live ad network and store integration is next; no revenue data yet.
